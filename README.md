# Clínica Dental Norwill — Web y Sistema de Reservas

Web pública con reservas online y panel de gestión para Clínica Dental Norwill (Perú), con WhatsApp como canal de confirmación.

- `web/` — landing pública (Next.js + Tailwind). Ver [`web/README.md`](web/README.md).
- `docs/brief-tecnico.md` — ficha técnica de referencia del proyecto.

Stack previsto para las siguientes fases: NestJS (API), PostgreSQL, Redis + BullMQ, Docker.

## Pendiente de confirmar con la clínica

- Número de WhatsApp, dirección, horario y enlace de Google Maps
- Nombre, colegiatura (COP), foto y biografía del doctor
- Logo, colores de marca y fotos del consultorio
- Precios finales de los tratamientos
- Razón social, RUC y dominio
- Revisión legal de la política de privacidad; formulario virtual del Libro de Reclamaciones (requiere backend)
