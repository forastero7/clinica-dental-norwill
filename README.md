# Clínica Dental Norwill — Web y Sistema de Reservas

Web pública con reservas online y panel de gestión para clínica dental en Perú, con WhatsApp como canal central de confirmación.

- Ficha técnica de referencia: [`docs/brief-tecnico.md`](docs/brief-tecnico.md)

Stack previsto: Next.js + Tailwind (frontend), NestJS (API), PostgreSQL, Redis + BullMQ, Docker.
